# Contributing

1. Create a focused branch from `main`.
2. Keep media additions separate from code changes and include verifiable license evidence.
3. Run `dotnet test OpenFlix.slnx` and `pnpm --dir src/openflix-web test`.
4. Open a pull request using conventional, descriptive commit messages.

Commits are signed where possible. Pull requests require green CI and review for identity, payment, rights, or deployment changes.
